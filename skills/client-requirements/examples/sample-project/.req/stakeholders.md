# 角色与诉求（第 2 步产物）

（虚构示例）

## 角色表

| 角色 | 姓名或岗位 | 类型 | 最在意什么 | 最怕什么 | 是否见过 |
|---|---|---|---|---|---|
| 总经理 | 周总 | 出钱/审批 | 当天能看到订单进度，减少延期 | 花了钱工人不用 | 是 |
| 生产主管 | 李主管 | 使用/审批 | 不再等统计员晚上录数据 | 工人嫌手机报工麻烦，推不下去 | 是 |
| 操作工 | 一班班长老赵 | 使用 | 报工不能比填纸单慢 | 报错了被扣工资 | 是 |
| 质检组长 | 王工 | 使用 | 新人能自己查到公差标准 | AI 答错导致批量不良 | 是 |
| IT 兼职 | 小陈 | 对接IT | 不影响用友 U8 | 新系统出问题要他半夜处理 | 是 |

## 冲突

- 周总要求每道工序都报工，老赵要求一天只报一次。按周总原话，进度看板以工单为单位即可，折中为"每完成一个工单的一道工序报一次"，需求拍板人周总已当场同意。

## 拍板人

需求拍板：周总
验收签字：李主管（报工）、王工（质检知识库）
付款审批：周总
